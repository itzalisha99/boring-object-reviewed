A make.fun bounty entry: one funny, true line reviewing the dullest everyday object I could name.

## The line

> The soap dish holds the soap, drains the water, and is somehow the dirtiest thing in the bathroom.

The joke is the object's own dullness: the thing whose whole job is keeping soap clean is itself the dirtiest thing in the room. It is a real, recognisable detail — every soap dish goes slimy — and the turn lands in the last words.

## How it works

`main.py` (Python standard library only) writes the review to `/output/entry.txt`. A `validate()` gate mirrors the bounty gate: the text must be UTF-8, 1 to 200 characters, not only white space, and a single line.

```sh
python3 main.py
```
